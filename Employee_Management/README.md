# Employee Salary Analytics System

## 📌 Project Overview

This project is an end-to-end Employee Salary Analytics System built using MySQL and Python.

It allows:

- Employee record management (CRUD operations)
- Salary analysis
- Data visualization
- Insight generation

## 🛠 Tools & Technologies Used

- MySQL
- SQLAlchemy
- Python
- Pandas
- Matplotlib

## 📊 Features

- Add, update, delete employee records
- Calculate average salary
- Identify highest and lowest paid employees
- Visualize salary distribution
- Role-wise salary analysis

## 📈 Insights Generated

- Average employee salary
- Salary distribution pattern
- Position-wise salary comparison

## 🚀 How to Run

1. Install required libraries:
   pip install pandas matplotlib sqlalchemy pymysql mysql-connector-python

2. Run employee_management.py
3. Run employee_analysis.py
